# Technical papers

Author: Deniz Bektas. Documentation license: CC BY 4.0.

All four papers are version 0.1.2, published in [the public repository](https://github.com/DenBek/ogard). The methodology, model profile and contradiction taxonomy they describe are version 0.1. The executable reference software has its own release numbers (Executable Reference Release v0.2.1 and later).

Version 0.1.2 corrects wording, version labels and references and makes the four papers consistent with one another, including minimum field lists, requirement levels and the indicative CIM crosswalk.

The Technical Whitepaper and the benchmark methodology link to the selected synthetic results produced in release 0.2.0 and re-verified in release 0.2.1. Full execution of the benchmark's broader protocol remains a separate evaluation stage.

Earlier paper versions remain available in Git history and in the archived releases (https://doi.org/10.5281/zenodo.22929401).
