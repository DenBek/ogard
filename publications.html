Publications

Four technical papers define OGARD. Each paper is version 0.1.2; the methodology, model profile and contradiction taxonomy they describe are version 0.1.

  4. OGARD Synthetic Benchmark Methodology and Validation Plan

    Deniz Bektas·Version 0.1.2·18 pages·PDF

    Defines how synthetic reconciliation, review routing, contradiction detection, auditability, and review burden should be evaluated and reproduced. It defines the full benchmark protocol and reports no results. A separate author-executed evaluation of five selected synthetic scenarios, first released in 0.2.0 and re-verified in 0.2.1, is available with the reference implementation.

  1. OGARD Executable Reference Release 0.2.2

    Deniz Bektas·Python reference implementation·GitHub·Zenodo

    Implements explicit equipment identity corroborated by event-time installation history, preserved evidence and conflicts, and review routing with scripted synthetic review events across five synthetic transformer scenarios, with a documented baseline comparison and 33 automated tests.
