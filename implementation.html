Reproduce

One command verifies the release

Use Python 3.10 or later from the repository root. No packages, credentials or cloud services are required.

python run_validation.py --output ../ogard-rerun --verify-snapshot

The command runs the regression tests, verifies both source layouts, generates decisions and comparisons, reproduces supplied outputs, checks local website links and verifies release fingerprints. Open the generated walkthrough in the output folder.

Both automatic methods receive identical source evidence with review events removed. The baseline uses an explicit equipment identifier, or a unique current installation at receipt time when that identifier is missing. OGARD corroborates identifiers using event-time installation history and routes missing identity or conflicts to review.

OGARD avoids the stale telemetry acceptance but requires more review. Both methods accept the shared-source identity error. Five decisions have known synthetic physical truth; the ambiguous case has no single truth label and is not counted as a correct match.

The final column replays scripted review events separately. The evaluation measures behavior on the selected synthetic cases. Utility-data accuracy and human reviewer performance require separate studies.
